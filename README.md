# War3CS2-Race-Ideas
Features race ideas created by me for War3CS2 server.

Not all races here are created by me, I have reworked/took ideas from the race(s). Look for **NOT MY DESIGN** next to the race name.
The Not My Design folder is races that I have reworked, but were not originally my idea, and have no category/folder to match.

Many of these races have not been balanced, but I've given good effort in doing so. The values are there as placeholders.
